تاريخ التشخيص: 19 نوفمبر 2026. التعديل مبني على `main` بعد دمج PR #195 (`7a72ef5`).

## الأدلة

- تقرير Page indexing (تحديث 16 نوفمبر): 71.5 ألف مفهرسة، 6.02 ألف غير مفهرسة، تشمل 985 خطأ 5xx، و1,897 صفحة اختار جوجل Canonical مختلفًا لها. لا يصح افتراض أن كل أسباب الاستبعاد أخطاء.
- تصدير Performance (15 سبتمبر–17 نوفمبر): 23 نقرة و3,651 ظهورًا (CTR إجمالي 0.63%). في أسبوع 5–11 أكتوبر: 1,124 ظهورًا؛ في أسبوع 9–15 نوفمبر: 23 ظهورًا.
- فحص LIVE في 19 نوفمبر: `/api/content-stats` أعاد Cloudflare 1101/1102 (HTTP 500/503)، و`/api/english-canary-health` أعاد 1102 (HTTP 503)، بينما عينة من الصفحات التجارية والمدونة أعادت 200.
- خطأ 1102 لدى Cloudflare يعني تجاوز حد CPU أو الذاكرة، ولا يثبت وحده أن كل أخطاء GSC الـ985 من نفس السبب.

## الملفات المخصصة للرفع

1. `commerce-entry.js`: إحصائيات الزيارة العامة تقرأ عدادات التوليد من Durable Object مباشرة، دون استدعاء `/api/generator-health` الضخم أو سجل AI V2 كاملًا.
2. `english-canary.js`: فحص الصحة الخفيف يقرأ ملخص Scheduler وعينة عامة صغيرة بدل تحميل State + Journal كاملين، مع بقاء مسار التوليد والكتابة كما كان.
3. `tests/public-health-lite.test.mjs`: إثبات عدم قراءة ملفات الحالة الضخمة وإبقاء القيم غير المتوفرة `null` بدل 0.

لم نغير Slugs أو المقالات أو الأكواد أو تاريخ النشر أو الفاصل الزمني. بيانات البلدان/Workers AI التي لا يمكن تأكيدها من الملخص الخفيف أصبحت `null` بدل رقم مصنوع، مع توضيح مصدر الإحصائيات في JSON.

## المطلوب بعد إصلاح موارد Worker لاستكمال Search Console

- من Indexing > Pages > Server error (5xx) > Export: مثال URL مع تاريخ آخر زحف وحالة Live URL Inspection. لا نعدل ملفات 985 صفحة دفعة واحدة قبل معرفة أمثلتها.
- من `Duplicate, Google chose different canonical than user` > Export: زوج URL الأصل والـGoogle-selected canonical لكل مثال. بعضها قد يكون تكرارًا مقصودًا.
- من Performance: مقارنة 28 يومًا مع الـ28 السابقة لمقارنة الصفحات/الكلمات بعد الإصلاح، لأن تقرير 3 أشهر لا يعزل سبب الانهيار وحده.
