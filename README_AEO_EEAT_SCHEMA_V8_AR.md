# NoonDealsNow — المرحلة الثانية: AEO و E-E-A-T و FAQ Schema

تُطبَّق هذه الحزمة بعد دمج المرحلة الأولى PR #197. لا تغيّر أكواد الخصم ولا Slugs ولا مقالات R2 المخزّنة ولا إعدادات التوليد.

## إصلاحات هذه المرحلة

1. صفحات `/saudi-arabia/noon-coupon-code*` و`/uae/noon-coupon-code*`: الأسئلة والأجوبة المرئية متطابقة نصيًا مع عناصر `FAQPage` في JSON-LD، وهي مستمدة من مصدر واحد.
2. صفحات `/saudi-arabia/coupon/...` و`/uae/coupon/...`: إظهار الأسئلة والأجوبة المعرّفة أصلًا في JSON-LD، مع إبقاء الـcanonical على صفحة `/coupon/{code}` الأساسية دون تغيير.
3. صفحات الأكواد الرئيسية: استبدال قائمة كلمات مفتاحية طويلة ظاهرة بفقرة توضح فائدة الصفحة للمتسوق فعلًا.
4. مدونة `/blog`: تعديل الوصف ليشير إلى فحوص الجودة دون الادعاء بأن كل مقال خضع لمراجعة بشرية فردية غير مثبتة.
