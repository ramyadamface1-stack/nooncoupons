# NoonDealsNow — إصلاح Sitemap وSchema وثقة المقالات V7

هذا الإصلاح يمنع إدراج صفحات أقسام ومنتجات إنجليزية في Sitemap عندما تكون الصفحة نفسها noindex لقلة المقالات الداعمة. ويضيف تحسينات محدودة لبيانات هوية الموقع ودقة المعلومات التحريرية دون تغيير المحتوى المخزن في R2.

## الملفات

1. `discovery-entry.js` — اتساق ملفات Sitemap مع قرار فهرسة الصفحات.
2. `brand-runtime.js` — صورة شعار SVG بدقة معلنة 256×256 وبيانات منظمة متسقة.
3. `commerce-pages-v2.js` و`english-canary.js` — أبعاد شعار المؤسسة في صفحات الأسواق والمقالات الإنجليزية.
4. `auto-platform.js` — إزالة ادعاء المراجعة التحريرية التلقائي الذي لا يثبت مراجعة بشرية.
5. `tests/sitemap-crawler-cpu-bounded.test.mjs` و`tests/seo-schema-image-trust-consistency.test.mjs` — اختبار السلوك والبيانات الوصفية.

## ما تغير

- صفحات أقسام الإنجليزية لا تدخل خرائط الموقع الديناميكية قبل استيفاء حد المحتوى الذي تستخدمه الصفحة نفسها.
- استثناء قسم الجوالات السعودية يبقى متاحًا كما كان. قسم Grocery الإمارات يدخل بعد وجود مقالتين مؤهلتين.
- صفحات المنتجات الإنجليزية لا تدخل Sitemap قبل وجود مقالتين مؤهلتين على الأقل، بدل إدراجها بمقالة واحدة.
- إزالة إدراج Grocery الإمارات غير المشروط من خريطة الصفحات الأساسية؛ الصفحة والرابط نفسهما لم يُحذفا.
- منع احتساب تكرار نفس رابط المقال مرتين ضمن أدلة صفحات الأقسام والمنتجات.
- تصريح أبعاد فعلية 256×256 لشعار الموقع الافتراضي مع الاحتفاظ بالشكل نفسه. الشعارات المخصصة لا تُنسب إليها أبعاد غير معروفة.
- تعديل عبارة «تمت مراجعة الصفحة تحريرياً» الآلية إلى وصف محايد لمعلومات الكوبون والسوق؛ لا تزال روابط السياسة التحريرية وفريق التحرير ظاهرة.
- تأكدنا أن كود المقالات **كان بالفعل** يعدّل أبعاد صورة المشاركة والبطاقة الرئيسية إلى 1600×1000 عند تقديم HTML؛ لم نكرر هذا الإصلاح.

## التحقق

- 616 اختبارًا نجحت محليًا، دون إخفاق.
- نجح فحص حزمة Worker المحلي بوضع dry-run، دون نشر أو اتصال إنتاجي.

## خطوات GitHub

ارفع التغييرات إلى فرع من `main` في المستودع `ramyadamface1-stack/nooncoupons`، وافتح Pull Request ثم تحقق من فحوص CI قبل الدمج. لا يُعتبر العمل منشورًا إلا بعد التأكد من النشر وعودة الموقع إلى HTTP 200.

مهم: هذا الإصلاح لا يعالج خطأ Cloudflare 1027 الخاص بالحد اليومي، ولا يغير DNS أو R2 أو التوليد أو الكوبونات أو روابط المقالات.
